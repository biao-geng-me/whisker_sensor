MSD P25937 · whisker PCB rev 2 · one whisker, end to end

Whisker signal chain

How one whisker (W1, gauges A and B) travels through the board: quarter bridge, INA351 amplifier, RC filter, CD4097B mux and ADS131M04 ADC to the ESP32 and the host. The other 15 whiskers are identical copies on other mux inputs. For where things plug in, see the header map.

Per gauge

  • Quarter bridge. The gauge (in the whisker) runs from 3V3 to the sense node, R3 (352 Ω) from the sense node to GND. A fixed arm R1/R2 makes 1.65 V. Only the sense pin carries signal; every odd header pin is the same 3V3 net, so gauge orientation does not matter.
  • INA351 (GS = GND, gain 10) amplifies the difference of the two arms and adds REF. Higher gauge resistance → lower sense voltage → higher output.
  • RC filter 1 k / 0.1 µF (≈1.6 kHz) on each output, then the net OUTn goes to a mux input. W1 gauge A = OUT1 = mux #1 X3, gauge B = OUT2 = mux #1 X4; both reach the ADC on AIN2 (COM_X1), at mux selects 3 and 4.
Vsense = 3.3 V × 352 / (352 + Rgauge)
OUT = 10 × (1.65 V − Vsense) + REF ≈ REF + 23 mV per Ω above 352 Ω

Shared parts

  • REF (AMP_REF_3V3) is one net for all 32 INA351s, set by R7/R8 with C4. It sets where zero bridge signal sits on the output. The ADC measures OUT against GND (AINxN grounded), so REF drift shows on every channel at once. Target 0.58 V (47 k / 10 k); as built it is unreliable (one divider copy empty, the other modified).
  • Mux and ADC. Two CD4097B (X and Y sections each) feed the four ADC inputs: mux #1 X → AIN2, Y → AIN3 (OUT1–16); mux #2 X → AIN0, Y → AIN1 (OUT17–32). One 3-bit select drives both muxes, so 8 selects × 4 ADC channels = 32 gauges per scan.
  • ADC ADS131M04: ±1.2 V full scale, gain 1, internal 1.2 V reference, OSR 128 at CLKIN 0.8 MHz (from ESP32 GPIO16) → 320 µs per conversion. Per select the firmware settles 250 µs, drops 3 conversions and keeps the 4th (sinc3 filter flushed), ≈1.6 ms per select, ≈76 scans/s.
  • Power: 5.5 V bench supply → J1 → MD1 buck → 3V3 for the bridges, amplifiers, muxes and ADC. The ESP32 is powered by USB and shares ground through a wire from MD1 pin 2.

How the ADC turns P − N into a signed number

The ADS131M04 is a delta-sigma converter. It never takes an absolute value and flips the sign: it continuously balances the input difference against ±1.2 V, and the sign falls out of that balance.

  1. Sample the difference. A small capacitor is switched between AINxP and AINxN, so it holds a charge proportional to P − N. Only the difference is stored, which is why each pin may sit anywhere from about −1.3 V to AVDD (3.3 V) while only P − N is limited to ±1.2 V.
  2. Accumulate. The charge, minus the feedback from the previous step, is added to an integrator (a running total).
  3. Decide one bit. A comparator looks at the sign of the total: positive gives 1 and subtracts +1.2 V worth of charge next clock, negative gives 0 and adds 1.2 V worth. This repeats every modulator clock (CLKIN / 2, 400 kHz now).
  4. Average the bits. To keep the integrator near zero, the average feedback must equal the input, so the fraction of 1s encodes P − N: fraction = (1 + Vin / 1.2 V) / 2. The sinc3 filter averages 128 bits (OSR 128) into one signed 24-bit result, 3125 per second now.
  • Out of range. Beyond ±1.2 V the ±1.2 V feedback can no longer balance the input, the stream becomes all 1s (or 0s) and the code saturates at 0x7FFFFF (0x800000). That is the “1200 mV / open” reading of an unconnected channel: its INA351 output heads for 3.3 V, legal for the pin but beyond 1.2 V of difference.
  • Why 3 results are discarded after a mux switch. The sinc3 filter’s window spans about three result periods of bits, so the first results after a switch still contain bits from the previous channel. The firmware keeps the 4th. A faster CLKIN shortens the window proportionally.
  • On this board AINxN is tied to GND and AINxP gets the amplifier output (0 to ~3.3 V), so only the 0 to +1.2 V half of the range is used; the amplifier cannot go below 0 V.
  • Better wiring would tie AINxN to REF: the same machinery would then measure OUT − REF, signed, over the full ±1.2 V, and REF drift would cancel in hardware.
