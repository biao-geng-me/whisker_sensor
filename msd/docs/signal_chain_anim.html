MSD P25937 · whisker DAQ · one reading, end to end · simulated in this page

Whisker signal chain, animated

By default a simplified board: 4 whiskers × 2 gauges on a 4×2 mux, feeding a 2-channel delta-sigma ADC (gauge A → AIN0, gauge B → AIN1), read by the MCU and framed to the host. The mux size and channel count are settings; the “real board 8×4” preset has all 32 gauges. Every curve, bit and number below comes from the simulation running in this page; change a setting and it is rebuilt. Static schematic and worked examples: whisker signal chain.

step

1 · Board, live

Each gauge's INA output runs through its RC to one input of a mux; the select connects one gauge per mux to an ADC channel. Bright wires: what the ADC sees now. Values update ~10 times a second.

2 · Scan timeline: mux slots, ADC inputs, conversions

One scan: the mux steps through the selects (shaded slots). Lines: voltage at each ADC pin. Boxes below: every conversion, kept (green) or read and discarded. Grey “not drawn” slots stand for selects the real board also scans but this small view leaves out (the “extra selects” setting, 0 in the 8×4 preset); they take the same time on the board, so they are kept here.

3 · At the switch: settle tail and which conversions are kept

Log scale: how far the pin still is from the new input after the switch, and that residual as each conversion's sinc3 window sees it. Windows that overlap the tail are dropped; the vertical line is now.

4 · Bit level: pin voltage → modulator bits → sinc3 windows

The modulator turns the pin voltage into 1-bit samples; the density of 1s tracks the input. Each result weighs 3·OSR bits with the sinc3 hump; windows overlap, one result every OSR bits (DRDY).

5 · sinc3 result → 24-bit word → DRDY → SPI → MCU

Each DRDY: every channel's 24-bit two's-complement result goes over SPI; the MCU keeps or drops it by the firmware policy and averages the kept ones per slot (plot: the current slot).

6 · Frame to the host, error vs the true input

One frame per scan: the reading per gauge vs the noiseless input, the error split into the settle tail and the rest (noise, ripple, comb, quantization); traces show the error scan by scan.
