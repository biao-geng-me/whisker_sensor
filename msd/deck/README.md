# DAQ PCB troubleshooting deck

Builds `DAQ_PCB_troubleshooting.pptx` (bench work 2026-10-19 to 10-22). `plots.py` reads the wavi_py logs and burst captures from `data/` (copy them from `/shared/rc/whiskers/MSD_P25937/bench_data_2026-10/logs` and `bursts`) and writes the `fig_*.png` figures (conda env with numpy, scipy, matplotlib, e.g. `py311`); `build_deck.py` assembles the slides with python-pptx (env `py312`). The `img_*.png` screenshots are crops of `msd/docs/whisker_signal_chain.html` and `whisker_header_map.html` rendered with headless chromium. Burst numbers on slides 12–14 are typed in from the `burst_spectrum.py` printouts. The built deck and a PDF are in `/shared/rc/whiskers/MSD_P25937/`.
