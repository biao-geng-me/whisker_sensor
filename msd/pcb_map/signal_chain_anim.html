MSD P25937 · whisker DAQ · one reading, end to end · simulated in this page

Whisker signal chain, animated

By default a simplified board: 4 whiskers × 2 gauges on a 4×2 mux, feeding a 2-channel delta-sigma ADC (gauge A → AIN0, gauge B → AIN1), read by the MCU and framed to the host. The mux size and channel count are settings; the “real board 8×4” preset has all 32 gauges. Every curve, bit and number below comes from the simulation running in this page; change a setting and it is rebuilt. Static schematic and worked examples: whisker signal chain.
